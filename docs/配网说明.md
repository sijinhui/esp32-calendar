# 墨水屏日历 · 配网说明

## 什么时候需要配网

设备在下面三种情况会进入**配网模式**：

- 第一次开机（还没设置过 WiFi）
- 已保存的 WiFi 连续 30 秒连不上（比如换了路由器、改了密码）——只在开发模式下；省电模式下请长按 BOOT 键
- 手动：**长按开发板上的 BOOT 键 3 秒**

进入配网模式后，设备会：

- 开一个 WiFi 热点，名字是 `EPaper-XXXX`（你这块板子是 `EPaper-7D24`），没有密码
- 打开蓝牙，等微信小程序连接（平时蓝牙是关着的，省电；配网结束、手机断开后自动关闭）
- 墨水屏上显示连接热点的二维码和步骤

下面两种方式任选一种。

## 方式一：手机连热点（什么都不用装）

1. 手机打开 WiFi 设置，连接 `EPaper-7D24`；或者用手机相机扫墨水屏上的二维码。
2. 连上后手机会自动弹出设置页面。没弹出的话，打开浏览器访问 `192.168.4.1`。
3. 在“附近的 WiFi”列表里点选家里的 WiFi，输入密码，点**连接**。
   - 设备只支持 **2.4GHz** WiFi。路由器把 2.4G 和 5G 分成两个名字的话，选 2.4G 那个。
4. 等最多 15 秒：
   - 显示“连接成功”和设备 IP，就完成了。设备热点随后会自动关闭，手机会回到原来的网络。
   - 如果手机先和热点断开了，一般说明设备已经连上 WiFi，热点也跟着关了。看墨水屏，或者浏览器访问 `http://esp32-calendar.local/` 确认。
   - 显示“密码错误”或“找不到这个 WiFi”的话，改好再连一次。原来的配置不会丢。
5. 同一个页面下面可以顺便填写**日历订阅**地址（每行一个），点保存。

## 方式二：微信小程序（蓝牙）

1. 打开小程序，点**添加设备**（已经添加过的话，点**重新配网**）。
2. 在搜到的设备里点 `EPaper-7D24`。安卓手机要先打开系统定位，否则搜不到蓝牙设备。
3. 设备会扫描附近的 WiFi，点选家里的 WiFi，输入密码，点**连接**。
4. 显示“设备已连上 WiFi”就完成了。可以接着点**添加日历订阅**。

之后只要手机和设备连在同一个 WiFi，小程序首页就能看到屏幕画面、手动同步、预览某天。iOS 第一次会询问是否允许微信访问“本地网络”，要选**允许**。

## 已经联网的设备要换 WiFi

1. 长按设备上的 BOOT 键 3 秒，设备进入配网模式。手动进入的配网模式会持续 10 分钟。
2. 按上面任一方式重新设置。

## 用电脑测试蓝牙（开发用）

在 macOS 系统自带的“终端”App 里运行。第一次会询问是否允许“终端”使用蓝牙，选允许。

```bash
cd ~/code/esp32-calendar
tools/ble_test.sh                     # 只读测试：搜索设备、查状态、扫 WiFi、检查错误处理，不改设备配置
tools/ble_test.sh --wifi 家里的WiFi    # 测试完再用蓝牙给设备配网，密码在终端里输入，不会显示
```

## 常见问题

| 现象 | 原因 / 办法 |
|---|---|
| WiFi 列表里没有 `EPaper-XXXX` | 设备不在配网模式：长按 BOOT 键 3 秒 |
| 连上热点后没弹出设置页 | 浏览器访问 `192.168.4.1` |
| 提示“找不到这个 WiFi” | 设备只支持 2.4GHz；或者离路由器太远 |
| 提示“密码错误” | 检查大小写；密码应为 8~63 位，开放网络留空 |
| 小程序搜不到设备 | 打开手机蓝牙并允许微信使用蓝牙；安卓手机还要打开定位 |
| 小程序提示“设备不在配网模式” | 已联网的设备要先长按 BOOT 键 3 秒 |
| 小程序首页连不上设备 | 手机和设备要在同一个 WiFi；iOS 要允许微信访问“本地网络” |
